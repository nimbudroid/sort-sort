# Fonts (visual style prototype)

| File | Source | Licence |
|---|---|---|
| `TitanOne-Regular.ttf` | Titan One by Rodrigo Fuenzalida, from google/fonts (unmodified) | SIL Open Font License 1.1, see `OFL-TitanOne.txt` |
| `Nunito-Black.ttf` | Nunito by Vernon Adams, Cyreal and Jacques Le Bailly, from google/fonts. Static weight-900 instance generated from the variable font with fontTools `varLib.instancer` (Unity's legacy font importer can't select weights in variable fonts) | SIL Open Font License 1.1, see `OFL-Nunito.txt` |

Both are loaded at runtime with `Resources.Load<Font>("Fonts/...")` by `ToyStyle`.
