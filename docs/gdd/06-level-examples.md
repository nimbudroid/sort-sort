# 06 — Level Examples (110 levels)

[← Index](README.md)

---

Level numbers match the campaign schedule in [Chapter 04](04-progression-difficulty.md#43-campaign-progression--what-the-player-learns). Tier labels: **N** = Normal (Easy/Medium), **🔥** = Hard, **💀** = Super Hard (Extreme), **🌀** = Chaos, **🧹** = Big Mess.

Each level lists: **Setup** (the "that's easy" beat), **Twist** (the "oh no" beat), and **Why it works** (what it teaches or the emotion it targets).
